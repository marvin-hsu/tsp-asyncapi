單一事實來源

HTTP API 與非同步 API 共用同一個 TypeSpec workspace。同一組 model 可以產出 OpenAPI 與 AsyncAPI。

經過驗證的轉換規則

文件裡每一組輸入輸出對照都由轉換器實際產生。涵蓋 model、scalar、enum、union、繼承、discriminator 與驗證關鍵字。

不靜默丟棄

emitter 無法表達的內容，一律以警告省略或回報錯誤，絕不靜默改寫。每個診斷都附上原因與修法。
