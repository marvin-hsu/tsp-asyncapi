One source of truth

Keep your HTTP API and your async API in one TypeSpec workspace. Emit OpenAPI and AsyncAPI from the same models.

Verified conversion rules

Every input/output pair in these docs was generated by the actual converter — models, scalars, enums, unions, inheritance, discriminators, and validation keywords.

No silent drops

Anything the emitter cannot represent is omitted with a warning or reported as an error — never silently rewritten. Each diagnostic is documented with its cause and fix.

Work in progress

Today the emitter produces the document skeleton and a complete info block. The schema conversion layer is implemented and unit-tested but not yet wired into the output; channels, operations, messages, servers, and protocol bindings are in development. What you get today →
